# Momo Blog · 使用与维护

[返回项目介绍](../README.md) · [Railway 部署](../README.md#railway-部署)

## 本地使用

需要 Node.js 24.14–24.x。在 macOS 上可以直接双击 `start-local.command` 启动；也可以在此文件夹打开终端执行：

```sh
npm install
npm run build
npm start
```

打开 **[本地首页](http://127.0.0.1:4318)**。默认仅监听本机，不会自动发布到互联网。

开发时运行 `npm run dev`，前台为 [开发预览](http://127.0.0.1:4317)，后台端口为 4318。

可复制 `.env.example` 为 `.env` 来配置端口和数据目录；`APP_URL` 必须与实际打开的地址一致。示例默认对应正式构建预览的 4318；使用开发前台时改为 `http://127.0.0.1:4317`。同时运行多个副本时，应使用不同端口和 `DATA_DIR`。

## 创建管理员

没有预设邮箱、密码或默认账号。第一次启动后：

1. 打开 [本地管理入口](http://127.0.0.1:4318/login)，线上部署使用你的网站域名加 `/login`；也可以点首页底部「管理」。
2. 从运行网站的机器上读取 `DATA_DIR/setup-token.txt`（默认 `data/setup-token.txt`）。Railway 请在服务的 Console 中读取；按 README 的卷挂载设置，执行 `cat /app/data/setup-token.txt`。若配置了 `SETUP_TOKEN` 环境变量，使用该值。
3. 输入你自己的邮箱和至少 12 位密码，点击「创建并登录」。

令牌在运行服务的机器上生成，线上与本地实例的令牌相互独立；创建管理员后初始化入口自动关闭。账号和会话保存在 SQLite，密码由 Better Auth 哈希保存。此阶段没有邮件服务和密码找回功能。

## 修改首页

登录后点击顶部「编辑页面」。标题、简介、页脚寄语可直接修改；每张卡片的「编辑」按钮打开相应内容面板。

- 项目、文章、照片、收藏、歌曲可新增、修改、删除，使用上下箭头调整顺序。
- 标题右侧的圆形头像可在「个人资料与联系」中上传、替换或移除，保存后生效。默认示例为 `assets/profile/avatar-demo.webp`，来源说明见 `assets/profile/README.md`。
- 首页照片在「个人资料」中选择。相册、文章、作品和收藏均使用独立素材标识。
- 图片支持 JPEG、PNG、WebP，最大 20 MB。服务端检查实际格式、完整解码并移除照片 EXIF，生成 WebP 和缩略图。暂不接收动画图或超过 4000 万像素的图片。
- 音乐支持 MP3、M4A、WAV，最大 50 MB、30 分钟。服务端校验实际格式、音频信息并进行完整解码；有视频轨道的文件不作为音乐接收。
- 面板里的修改先进入草稿。「返回首页预览」只关闭面板；顶部「保存修改」成功后才更新公开内容。
- 「取消」恢复公开内容。保存失败会保留草稿，可重试；离开未保存页面时浏览器会提醒。
- 多窗口保存使用内容版本检查。收到冲突提示时，请先保留自己需要的文字，然后取消并重新编辑最新版本，避免覆盖另一个窗口的修改。

草稿只保存在当前打开的页面，不承诺关闭标签页后恢复。上传但未发布的素材只有管理员可以访问；取消编辑不会自动删除已上传文件，方便后续人工整理备份。

## 访客功能

顶部导航切换首页、项目、文字、相册和收集；四个栏目在导航下方全屏展示，内容滚动时导航保持可见。栏目和项目／文章详情拥有独立地址，支持直接打开、刷新及浏览器前进后退。相册以瀑布流照片墙展示，大幅主图和高低错落的 Bento 卡片自动适配屏幕；点击照片可查看完整大图，支持左右方向键、缩略图和前后按钮，Esc 或「返回照片墙」恢复原来的浏览位置。收集可分类筛选与搜索。切换栏目不中断音乐，页面底部保留播放／暂停。留言表单和素材说明以弹窗显示，Esc 可关闭。

首页照片每次进入首页时从相册随机选择一张，停留期间保持不变；点击照片打开的就是当前这一张。编辑模式固定显示「首页展示照片」以便预览，空相册显示占位。

音乐卡片底部显示 GitHub、Email、小红书入口及实时点赞数；社交链接可在「个人资料与联系」中修改。

音乐使用一个音频实例，可播放、暂停、拖动进度、切换歌曲和调整音量。音乐卡片右上角打开播放设置。浏览器记住进度与音量，刷新后保持暂停。

音乐封面优先显示手动上传的图片，其次自动读取 MP3／M4A 等音频内嵌的封面，无可用封面时显示默认唱片。已上传的旧歌曲也会自动读取；提取结果保存在素材目录，不修改歌曲或公开内容版本。编辑音乐时可上传自定义图片，或点击「恢复自动封面」。

悉尼时钟和日历自动处理夏令时。天气由服务端读取 Open-Meteo，15 分钟缓存；无可用数据时显示「天气暂不可用」，旧缓存会明确标注。天气联网才能更新。

签到按悉尼日期每天每个浏览器一次。今日访客按签名浏览器 Cookie 去重；累计访问按页面加载计数；运行天数从数据库首次创建的悉尼日期算起。管理员登录后的预览及 `/login` 页面不计数。点赞保存在数据库，可取消。清除 Cookie、换浏览器或换设备会成为新的匿名身份；这不是跨设备账号统计。

## 私人留言

点击「聊聊」可填写称呼、可选回复邮箱和留言（最多 2000 字）。留言保存在本站 SQLite 数据库，不公开展示，不会自动发送邮件。未提交内容仅暂存在当前标签页的会话存储，关闭弹窗或刷新后可继续填写；发送失败保留内容，成功后清空。相同提交标识重试不会生成重复留言。

管理员登录后，顶部「留言箱」可分页查看、标记已读／未读和删除留言。所有读取和管理接口都校验管理员会话。提交接口校验来源、输入长度，并限制每个 IP 每 15 分钟 10 次请求；提供隐藏字段拦截简单垃圾提交。

## 示例素材

初始文案依据设计稿，文章正文为可替换示例。悉尼主图为 AI 生成示意图，其他照片来自 Unsplash，音乐为已有的原创演示旋律。来源在首页「素材说明」以及 `assets/demo/LICENSE.md`、`assets/demo/photos.json` 和 `assets/demo/SOURCES.md` 中注明。音乐不是设计图中歌曲的商业录音。

实际内容为 HTML 和可编辑数据；没有把设计稿作为整页背景。默认笔记应用示意图由 HTML 绘制，上传项目封面即可替换。

## 数据与备份

- `data/site.db`：公开内容、版本、单管理员账号、会话、签到、访问、点赞及私人留言。
- `data/uploads/`：独立上传原音频、转码图片和缩略图。
- `data/.auth-secret`：本地会话签名密钥。
- `data/setup-token.txt`：一次性管理员初始化令牌。
- `assets/demo/`：首次启动时导入的示例素材，仅数据库为空时初始化。

备份前停止服务，然后复制整个 `data/` 目录。恢复时整体放回；不要只复制 SQLite 主文件而遗漏正在使用的 WAL 文件。`data/`、所有本地环境文件（保留 `.env.example`）、数据库备份、`artifacts/` 内的验收截图和测试产物、依赖及构建结果均已排除在 Git 之外。README 使用的示例截图单独保存在 `docs/images/`。不要把账号数据、令牌和签名密钥公开，也不要用 `git add -f` 强制加入这些文件。

示例初始化只在空数据库中执行。示例种子不会覆盖现有数据库。保留原数据目录更新代码时，个人内容继续保留；Railway 必须将数据目录挂载到持久卷，容器临时文件不会随重新部署保留。更新或迁移前请备份整个数据目录。

提交前运行 `npm run check:publish`，检查暂存区里是否意外加入数据库、上传目录、环境配置、密钥或本机个人路径。Git 忽略规则不能移除已经提交到历史里的文件，因此请在首次提交前检查。

## 验证

```sh
npm run typecheck
npm run build
npm test
npm run test:browser
```

接口测试创建独立临时 SQLite 数据库，退出时清理。浏览器验收使用临时账号和独立数据目录，启动本地 4322 端口，结束后清理；不会修改正常预览的数据。

浏览器验收默认使用 macOS Google Chrome；可设置 `CHROME_BIN` 指向其他 Chrome，也可先执行 `npx playwright install chromium` 使用 Playwright 浏览器。截图与验收记录输出到 `artifacts/`。字体优先使用 Google Fonts 的 DM Sans / Space Grotesk，无法联网时使用系统字体。

## 页面与接口

固定三行 Bento；桌面 1600×1000、1440×900 完整一屏，1100px 以下两列、620px 以下单列滚动。提供独立栏目、项目详情和文章正文预览；不包含多人博客管理、全站自由拖拽或主题编辑。

| 接口 | 用途 |
| --- | --- |
| `GET /api/home` | 公开内容与版本 |
| `PUT /api/home` | 管理员保存内容，检查版本与素材引用 |
| `POST /api/media?kind=image\|audio` | 管理员上传实际格式校验 |
| `GET /api/media/:id` | 图片、缩略图与 Range 音频；未发布素材限管理员 |
| `GET /api/state`、`GET /api/admin/status` | 会话及初始化状态 |
| `POST /api/setup` | 使用服务器初始化令牌创建唯一管理员 |
| `/api/auth/sign-in/email`、`/api/auth/sign-out` | 登录、退出 |
| `GET /api/stats`、`POST /api/visits` | 签名匿名身份和真实统计 |
| `POST /api/checkin`、`POST /api/likes` | 幂等签到和点赞状态 |
| `POST /api/messages` | 提交私人留言；输入校验、限流和重试去重 |
| `GET /api/messages?page=1` | 管理员分页查看留言 |
| `PATCH /api/messages/:id`、`DELETE /api/messages/:id` | 管理员标记已读或删除 |
| `GET /api/weather` | 悉尼 Open-Meteo 天气缓存 |

## 反向代理与限流

当前 Express 应用未配置 `trust proxy`，请求限流默认按直接连接的 IP 计算。在 Railway 等反向代理后，可能将多个访客视为同一来源，并记录 `ERR_ERL_UNEXPECTED_X_FORWARDED_FOR` 提示。公开接待更多访问前，应按实际代理链配置可信代理并验证限流；不要直接信任所有转发头。[Express 说明](https://expressjs.com/en/guide/behind-proxies.html)。
